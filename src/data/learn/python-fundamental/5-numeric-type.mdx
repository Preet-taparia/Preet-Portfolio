## Overview

Python provides three built-in numeric types: `int`, `float`, and `complex`. These types support all standard mathematical operations and provide extensive functionality for numerical computations.

## 1. Integer (int) - Arbitrary Precision Integers

### Description
Python integers have unlimited precision, meaning they can represent arbitrarily large numbers without overflow. This makes Python particularly suitable for mathematical computations requiring high precision.

### Constructor
```python
# Various ways to create integers
int()                   # 0 (default)
int(42)                 # 42
int("42")               # 42 (from string)
int("1010", 2)          # 10 (from binary string)
int("FF", 16)           # 255 (from hexadecimal)
int(3.14)               # 3 (truncates float)
int(True)               # 1 (from boolean)
```

### Methods
```python
# Instance methods
num = 42
num.bit_length()         # Number of bits needed to represent the number
num.to_bytes(length, byteorder)  # Convert to bytes
num.as_integer_ratio()   # Return (numerator, denominator) tuple

# Class methods
int.from_bytes(bytes, byteorder)  # Create int from bytes
```

### Special Properties
```python
# Integer caching (-5 to 256 are cached for efficiency)
a = 100
b = 100
print(a is b)  # True - same object in memory

# Arbitrary precision
huge_num = 2 ** 1000  # No overflow errors
print(huge_num)       # Works perfectly

# Binary operations
x = 42
print(bin(x))         # '0b101010' - binary representation
print(oct(x))         # '0o52' - octal representation
print(hex(x))         # '0x2a' - hexadecimal representation

# Bitwise operations
print(x & 15)         # 10 - bitwise AND
print(x | 15)         # 47 - bitwise OR
print(x ^ 15)         # 37 - bitwise XOR
print(~x)             # -43 - bitwise NOT
print(x << 2)         # 168 - left shift
print(x >> 2)         # 10 - right shift
```

### Use Cases
- Mathematical calculations requiring precision
- Counting and indexing
- Bitwise operations and flags
- Cryptographic computations

## 2. Float (float) - Double-Precision Floating Point

### Description
Python floats are implemented as IEEE 754 double-precision floating-point numbers. They provide approximately 15-17 decimal digits of precision but can have representation issues with decimal numbers.

### Constructor
```python
# Various ways to create floats
float()                  # 0.0 (default)
float(42)               # 42.0 (from int)
float("3.14")           # 3.14 (from string)
float("inf")            # inf (positive infinity)
float("-inf")           # -inf (negative infinity)
float("nan")            # nan (not a number)
float(True)             # 1.0 (from boolean)
```

### Methods
```python
# Instance methods
x = 3.14159
x.as_integer_ratio()     # (7074237752025165, 2251799813685248)
x.is_integer()           # False - check if value is integer
x.hex()                  # '0x1.921f9f01b866ep+1' - hex representation

# Class method
float.fromhex(hex_string)  # Create float from hex string
```

### Special Properties and Considerations
```python
import sys
import math

# Float precision issues
print(0.1 + 0.2)         # 0.30000000000000004 (not exactly 0.3)
print(0.1 + 0.2 == 0.3)  # False

# Proper float comparison
print(math.isclose(0.1 + 0.2, 0.3))  # True

# Float properties
print(sys.float_info)    # Detailed float implementation info

# Special float values
print(math.isfinite(1.0))    # True
print(math.isnan(float('nan')))  # True
print(math.isinf(float('inf'))) # True

# Float limits
print(sys.float_info.max)    # Largest representable float
print(sys.float_info.min)    # Smallest positive normalized float
print(sys.float_info.epsilon)  # Smallest difference
```

### Alternative Solutions for Precision
```python
from decimal import Decimal, getcontext
from fractions import Fraction

# Decimal for exact decimal arithmetic
getcontext().prec = 50  # Set precision to 50 digits
d1 = Decimal('0.1')
d2 = Decimal('0.2')
print(d1 + d2)  # Exactly 0.3

# Fractions for exact rational arithmetic
f1 = Fraction(1, 3)
f2 = Fraction(2, 3)
print(f1 + f2)  # Exactly 1
```

### Use Cases
- General numerical computations
- Scientific calculations
- Graphics and game development
- Financial calculations (with caution - consider Decimal for exact arithmetic)

## 3. Complex (complex) - Complex Numbers

### Description
Python complex numbers consist of a real and imaginary part, both represented as floats. They support all arithmetic operations and provide access to mathematical functions for complex analysis.

### Constructor
```python
# Various ways to create complex numbers
complex()                # (0+0j) - default
complex(3)              # (3+0j) - real part only
complex(3, 4)           # (3+4j) - real and imaginary parts
complex("3+4j")         # (3+4j) - from string
complex("5j")           # (0+5j) - imaginary only

# Using literal notation
z1 = 3 + 4j             # Direct notation
z2 = 3 + 4J             # J is also valid
z3 = 4j                 # Pure imaginary
```

### Key Attributes
```python
z = 3 + 4j
print(z.real)           # 3.0 - real part
print(z.imag)           # 4.0 - imaginary part
```

### Methods
```python
z = 3 + 4j
z.conjugate()           # (3-4j) - complex conjugate
```

### Complex Number Operations
```python
z1 = 3 + 4j
z2 = 1 + 2j

# Arithmetic operations
print(z1 + z2)          # (4+6j)
print(z1 - z2)          # (2+2j)
print(z1 * z2)          # (-5+10j)
print(z1 / z2)          # (2.2-0.4j)

# Magnitude and phase
print(abs(z1))          # 5.0 - magnitude/modulus
import cmath
print(cmath.phase(z1))  # 0.9272952180016122 - phase angle in radians
print(cmath.polar(z1))  # (5.0, 0.9272952180016122) - polar form

# Complex mathematical functions
print(cmath.sqrt(-1))   # 1j - square root of negative number
print(cmath.exp(1j * cmath.pi))  # (-1+0j) - Euler's formula
```

### Use Cases
- Signal processing and Fourier transforms
- Electrical engineering calculations
- Mathematical analysis and complex analysis
- Quantum computing simulations
- Graphics and 2D transformations

## Common Numeric Operations

### Arithmetic Operators
```python
# All numeric types support these operations
+ - * /        # Basic arithmetic
//             # Floor division
%              # Modulo
**             # Exponentiation
abs()          # Absolute value
divmod(a, b)   # Returns (a//b, a%b)
pow(a, b, c)   # Modular exponentiation: (a**b) % c
```

### Comparison Operators
```python
== != < <= > >=    # All numeric types are comparable
```

### Type Conversion
```python
# Conversion between numeric types
int(3.14)      # 3 - truncates toward zero
float(42)      # 42.0
complex(3, 4)  # (3+4j)

# Type hierarchy for mixed operations
# int -> float -> complex
result = 1 + 2.0      # Result is float (2.0)
result = 1 + 2j       # Result is complex (1+2j)
result = 1.0 + 2j     # Result is complex (1+2j)
```

### Mathematical Functions
```python
import math
import cmath

# Math module (for real numbers)
math.sqrt(16)         # 4.0
math.sin(math.pi/2)   # 1.0
math.log(math.e)      # 1.0
math.factorial(5)     # 120

# Cmath module (for complex numbers)
cmath.sqrt(-1)        # 1j
cmath.sin(1+2j)       # Complex sine
cmath.log(1+1j)       # Complex logarithm
```

## Performance Considerations

### Integer Performance
- Small integers (-5 to 256) are cached
- Large integers use arbitrary precision arithmetic
- Bitwise operations are very fast

### Float Performance
- IEEE 754 double precision
- Hardware-accelerated operations
- Memory efficient for arrays

### Complex Performance
- Implemented as pair of floats
- Complex operations may be slower than real equivalents
- Consider numpy for array operations

## Best Practices

1. **Use appropriate precision**: Choose int for exact counting, float for general math, Decimal for financial calculations
2. **Handle float precision**: Use `math.isclose()` for float comparisons
3. **Consider alternatives**: Use fractions.Fraction for exact rational arithmetic
4. **Type checking**: Use `isinstance()` to check numeric types
5. **Performance**: Be aware of integer caching and complex number overhead
