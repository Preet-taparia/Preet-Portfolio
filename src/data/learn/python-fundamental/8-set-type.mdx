#### 4.4.1 Set (set) - Hash Table for Unique Elements
```python
# Set operations and mathematics
set1 = {1, 2, 3, 4}
set2 = {3, 4, 5, 6}

# Set operations
union = set1 | set2                      # {1, 2, 3, 4, 5, 6}
intersection = set1 & set2               # {3, 4}
difference = set1 - set2                 # {1, 2}
symmetric_diff = set1 ^ set2             # {1, 2, 5, 6}

# Set comprehensions
squares_set = {x**2 for x in range(10)}
even_squares = {x**2 for x in range(10) if x % 2 == 0}

# Frozenset (immutable set)
frozen = frozenset([1, 2, 3, 4])
# Can be used as dictionary keys or in other sets
nested_sets = {frozenset([1, 2]), frozenset([3, 4])}
```



#### 2.5.1 Set Implementation & Performance
```python
# Sets are implemented as hash tables
s1 = {1, 2, 3, 4, 5}
s2 = {4, 5, 6, 7, 8}

# Set operations
print(s1 | s2)  # Union: {1, 2, 3, 4, 5, 6, 7, 8}
print(s1 & s2)  # Intersection: {4, 5}
print(s1 - s2)  # Difference: {1, 2, 3}
print(s1 ^ s2)  # Symmetric difference: {1, 2, 3, 6, 7, 8}

# Set comparisons
print(s1 <= s2)  # Subset check
print(s1 >= s2)  # Superset check
print(s1.isdisjoint(s2))  # No common elements

# Frozen sets (immutable)
fs = frozenset([1, 2, 3, 4])
print(hash(fs))  # Frozen sets are hashable
```

#### 2.5.2 Set Comprehensions & Operations
```python
# Set comprehensions
squares = {x**2 for x in range(10)}
even_squares = {x for x in squares if x % 2 == 0}

# Set operations with methods
s1 = {1, 2, 3}
s2 = {3, 4, 5}

s1.update([4, 5, 6])  # Add multiple elements
s1.intersection_update(s2)  # Keep only common elements
s1.difference_update(s2)  # Remove elements in s2
s1.symmetric_difference_update(s2)  # Keep only unique elements
```
