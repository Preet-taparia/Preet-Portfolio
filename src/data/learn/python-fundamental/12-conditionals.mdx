**Conditional Statements**

- **`if` / `elif` / `else`**

  ```python
  if x > 0:
      print("positive")
  elif x == 0:
      print("zero")
  else:
      print("negative")
  ```

- **Nested `if`** blocks
- **Ternary (conditional) expressions**

  ```python
  status = "adult" if age >= 18 else "minor"
  ```
