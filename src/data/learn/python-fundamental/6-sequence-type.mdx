# Python Sequence Types - Complete Guide

## Overview

Sequence types in Python are ordered collections that support indexing, slicing, and iteration. The main sequence types are `str`, `list`, `tuple`, and `range`. They share common operations but have different mutability characteristics and use cases.

## Common Sequence Operations

All sequence types support these operations:

```python
# Indexing and slicing
seq[i]          # Get item at index i
seq[i:j]        # Slice from i to j-1
seq[i:j:k]      # Slice with step k

# Length and membership
len(seq)        # Number of items
item in seq     # Membership test
item not in seq # Negative membership test

# Concatenation and repetition
seq1 + seq2     # Concatenation
seq * n         # Repetition

# Iteration
for item in seq:    # Forward iteration
for item in reversed(seq):  # Reverse iteration

# Min/max (for comparable items)
min(seq)        # Minimum item
max(seq)        # Maximum item

# Counting and finding
seq.count(item) # Count occurrences
seq.index(item) # Find first index
```

## 1. String (str) - Immutable Unicode Sequences

### Description

Strings in Python are immutable sequences of Unicode characters. They support a rich set of methods for text processing and manipulation. Python strings are implemented with memory optimization features like interning for small strings.

### Constructor

```python
# Various ways to create strings
str()                    # '' (empty string)
str(42)                 # '42' (from number)
str([1, 2, 3])          # '[1, 2, 3]' (from any object)
"hello"                 # String literal
'hello'                 # Single quotes
"""multiline string"""  # Triple quotes
r"raw string\n"         # Raw string (no escape processing)
f"Hello {name}"         # f-string (formatted string literal)
```

### Key Attributes

- **No specific attributes** - strings are immutable sequences

### Methods - String Testing

```python
s = "Hello World"

# Character type testing
s.isalnum()     # True if all alphanumeric
s.isalpha()     # True if all alphabetic
s.isascii()     # True if all ASCII
s.isdecimal()   # True if all decimal characters
s.isdigit()     # True if all digits
s.isidentifier() # True if valid Python identifier
s.islower()     # True if all lowercase
s.isnumeric()   # True if all numeric characters
s.isprintable() # True if all printable
s.isspace()     # True if all whitespace
s.istitle()     # True if titlecased
s.isupper()     # True if all uppercase
```

### Methods - String Transformation

```python
s = "  Hello, World!  "

# Case conversion
s.lower()       # '  hello, world!  '
s.upper()       # '  HELLO, WORLD!  '
s.capitalize()  # '  hello, world!  '
s.title()       # '  Hello, World!  '
s.swapcase()    # '  hELLO, wORLD!  '
s.casefold()    # Aggressive lowercase for comparisons

# Whitespace handling
s.strip()       # 'Hello, World!' - remove leading/trailing whitespace
s.lstrip()      # 'Hello, World!  ' - remove leading whitespace
s.rstrip()      # '  Hello, World!' - remove trailing whitespace
s.strip('!')    # '  Hello, World  ' - remove specific characters

# Padding and alignment
s.center(20)    # Center string in field of width 20
s.ljust(20)     # Left justify
s.rjust(20)     # Right justify
s.zfill(10)     # Pad with zeros on left
```

### Methods - String Searching and Replacing

```python
text = "The quick brown fox jumps over the lazy dog"

# Finding substrings
text.find('quick')      # 4 - index of first occurrence
text.rfind('the')       # 31 - index of last occurrence
text.index('quick')     # 4 - like find() but raises ValueError if not found
text.rindex('the')      # 31 - reverse index

# Boolean searches
text.startswith('The')  # True
text.endswith('dog')    # True
text.startswith(('A', 'The'))  # True - multiple prefixes

# Counting
text.count('o')         # 4 - count occurrences

# Replacing
text.replace('fox', 'cat')      # Replace all occurrences
text.replace('o', '0', 2)       # Replace first 2 occurrences
```

### Methods - String Splitting and Joining

```python
# Splitting
data = "apple,banana,cherry"
fruits = data.split(',')        # ['apple', 'banana', 'cherry']
words = "hello world".split()   # ['hello', 'world'] - split on whitespace
lines = "line1\nline2\nline3".splitlines()  # ['line1', 'line2', 'line3']

# Partitioning
text = "name=value"
name, sep, value = text.partition('=')  # ('name', '=', 'value')
name, sep, value = text.rpartition('=') # Right partition

# Joining
separator = ', '
result = separator.join(['apple', 'banana', 'cherry'])  # 'apple, banana, cherry'
```

### String Formatting

```python
name = "Alice"
age = 30
score = 95.5

# f-strings (Python 3.6+) - Recommended
f"Name: {name}, Age: {age}, Score: {score:.1f}"

# str.format() method
"Name: {}, Age: {}, Score: {:.1f}".format(name, age, score)
"Name: {name}, Age: {age}".format(name=name, age=age)

# % formatting (legacy)
"Name: %s, Age: %d, Score: %.1f" % (name, age, score)

# Advanced formatting
f"{score:>10.2f}"      # Right-align, width 10, 2 decimal places
f"{age:04d}"           # Zero-pad to 4 digits
f"{name:<20}"          # Left-align, width 20
```

### String Encoding and Unicode

```python
# Unicode handling
text = "Hello, 世界! 🌍"
print(len(text))                    # Character count: 11
encoded = text.encode('utf-8')      # b'Hello, \xe4\xb8\x96\xe7\x95\x8c! \xf0\x9f\x8c\x8d'
print(len(encoded))                 # Byte count: 15
decoded = encoded.decode('utf-8')   # Back to string

# Different encodings
text.encode('ascii', 'ignore')      # Ignore non-ASCII characters
text.encode('ascii', 'replace')     # Replace with '?'
```

### String Interning and Performance

```python
# String interning (automatic for small strings)
a = "hello"
b = "hello"
print(a is b)  # True - same object in memory

# Manual interning
import sys
s1 = sys.intern("hello world")
s2 = sys.intern("hello world")
print(s1 is s2)  # True

# Performance considerations
# Avoid: result = ""
# for item in items:
#     result += str(item)  # O(n²) complexity

# Better: use join()
result = "".join(str(item) for item in items)  # O(n) complexity
```

## 2. List (list) - Mutable Dynamic Arrays

### Description

Lists are mutable sequences implemented as dynamic arrays (resizable arrays). They can store items of any type and provide efficient operations for adding, removing, and accessing elements.

### Constructor

```python
# Various ways to create lists
list()                  # [] (empty list)
list("hello")          # ['h', 'e', 'l', 'l', 'o']
list(range(5))         # [0, 1, 2, 3, 4]
[1, 2, 3]              # List literal
[x**2 for x in range(5)]  # List comprehension: [0, 1, 4, 9, 16]
```

### Key Attributes

- **No specific attributes** - lists are mutable sequences

### Methods - Adding Elements

```python
lst = [1, 2, 3]

# Adding single elements
lst.append(4)           # [1, 2, 3, 4] - add to end
lst.insert(0, 0)        # [0, 1, 2, 3, 4] - insert at index

# Adding multiple elements
lst.extend([5, 6])      # [0, 1, 2, 3, 4, 5, 6] - extend with iterable
lst += [7, 8]           # [0, 1, 2, 3, 4, 5, 6, 7, 8] - in-place concatenation
```

### Methods - Removing Elements

```python
lst = [1, 2, 3, 2, 4, 2, 5]

# Remove by value
lst.remove(2)           # [1, 3, 2, 4, 2, 5] - removes first occurrence

# Remove by index
item = lst.pop()        # 5 - remove and return last item: [1, 3, 2, 4, 2]
item = lst.pop(0)       # 1 - remove and return item at index 0: [3, 2, 4, 2]

# Remove all
lst.clear()             # [] - remove all elements
```

### Methods - Sorting and Reversing

```python
numbers = [3, 1, 4, 1, 5, 9, 2, 6]

# In-place operations
numbers.sort()                      # [1, 1, 2, 3, 4, 5, 6, 9]
numbers.sort(reverse=True)          # [9, 6, 5, 4, 3, 2, 1, 1]
numbers.reverse()                   # [1, 1, 2, 3, 4, 5, 6, 9]

# Custom sorting
students = [('Alice', 85), ('Bob', 90), ('Charlie', 78)]
students.sort(key=lambda x: x[1])   # Sort by grade
students.sort(key=lambda x: x[1], reverse=True)  # Descending

# Using operator module
from operator import itemgetter
students.sort(key=itemgetter(1))    # Sort by second element
```

### List Comprehensions and Expressions

```python
# Basic list comprehension
squares = [x**2 for x in range(10)]

# With condition
even_squares = [x**2 for x in range(10) if x % 2 == 0]

# Nested comprehensions
matrix = [[i*j for j in range(3)] for i in range(3)]
# [[0, 0, 0], [0, 1, 2], [0, 2, 4]]

# Flattening
nested = [[1, 2], [3, 4], [5, 6]]
flattened = [item for sublist in nested for item in sublist]  # [1, 2, 3, 4, 5, 6]
```

### Advanced List Operations

```python
# Slicing with assignment
lst = [1, 2, 3, 4, 5]
lst[1:3] = [20, 30]     # [1, 20, 30, 4, 5]
lst[::2] = [10, 30, 50] # [10, 20, 30, 4, 50]

# List unpacking
a, b, *rest, last = [1, 2, 3, 4, 5, 6]
print(a, b, rest, last)  # 1 2 [3, 4, 5] 6

# Copying lists
original = [1, 2, [3, 4]]
shallow_copy = original.copy()      # or original[:]
import copy
deep_copy = copy.deepcopy(original)
```

### Performance Considerations

```python
import sys

# Dynamic array growth
lst = []
for i in range(20):
    lst.append(i)
    print(f"Length: {len(lst)}, Memory: {sys.getsizeof(lst)}")

# Performance tips
# 1. Use list comprehensions when possible (faster than loops)
# 2. Prefer extend() over repeated append() calls
# 3. Use deque for frequent insertions/deletions at beginning
# 4. Consider array.array for numeric data
```

## 3. Tuple (tuple) - Immutable Ordered Sequences

### Description

Tuples are immutable sequences, similar to lists but cannot be modified after creation. They're often used for heterogeneous data and as dictionary keys. Small tuples may be cached for efficiency.

### Constructor

```python
# Various ways to create tuples
tuple()                 # () (empty tuple)
tuple([1, 2, 3])       # (1, 2, 3) from list
(1, 2, 3)              # Tuple literal
1, 2, 3                # Tuple packing (parentheses optional)
(42,)                  # Single element tuple (comma required)
tuple("hello")         # ('h', 'e', 'l', 'l', 'o')
```

### Key Attributes

- **No specific attributes** - tuples are immutable sequences

### Methods

```python
# Tuples have only two methods
t = (1, 2, 3, 2, 4, 2)
t.count(2)             # 3 - count occurrences
t.index(3)             # 2 - find first index
```

### Tuple Operations

```python
# Tuple packing and unpacking
coordinates = 3, 4, 5           # Packing
x, y, z = coordinates           # Unpacking

# Extended unpacking
data = (1, 2, 3, 4, 5)
first, *middle, last = data     # first=1, middle=[2, 3, 4], last=5

# Multiple assignment
a, b = 1, 2
a, b = b, a                     # Swap values elegantly

# Function returns
def get_name_age():
    return "Alice", 25

name, age = get_name_age()      # Unpack returned tuple
```

### Named Tuples

```python
from collections import namedtuple

# Create a named tuple class
Point = namedtuple('Point', ['x', 'y'])
Person = namedtuple('Person', ['name', 'age', 'city'])

# Create instances
p = Point(3, 4)
person = Person('Alice', 30, 'New York')

# Access by name or index
print(p.x, p.y)                # 3 4
print(p[0], p[1])              # 3 4

# Named tuple methods
print(p._asdict())             # {'x': 3, 'y': 4}
p2 = p._replace(x=5)           # Point(x=5, y=4) - create new instance
print(p._fields)               # ('x', 'y')
```

### Use Cases and Benefits

```python
# 1. Heterogeneous data
student = ("Alice", 20, "Computer Science", 3.8)

# 2. Dictionary keys (immutable and hashable)
locations = {
    (0, 0): "origin",
    (1, 1): "northeast",
    (-1, -1): "southwest"
}

# 3. Function arguments
def print_coordinates(x, y, z):
    print(f"x={x}, y={y}, z={z}")

coords = (1, 2, 3)
print_coordinates(*coords)      # Unpack tuple as arguments

# 4. Multiple return values
def divmod_custom(a, b):
    return a // b, a % b

quotient, remainder = divmod_custom(17, 5)
```

## 4. Range (range) - Immutable Arithmetic Sequences

### Description

Range objects represent immutable sequences of integers, commonly used in for loops. They're memory-efficient as they store only the start, stop, and step values rather than all individual values.

### Constructor

```python
# Various ways to create ranges
range(5)                # range(0, 5) - 0 to 4
range(1, 6)             # range(1, 6) - 1 to 5
range(0, 10, 2)         # range(0, 10, 2) - 0, 2, 4, 6, 8
range(10, 0, -1)        # range(10, 0, -1) - 10 to 1 (decreasing)
```

### Key Attributes

```python
r = range(1, 10, 2)     # 1, 3, 5, 7, 9
print(r.start)          # 1
print(r.stop)           # 10
print(r.step)           # 2
```

### Methods

```python
r = range(1, 10, 2)
r.count(5)              # 1 - count occurrences
r.index(5)              # 2 - find first index
```

### Range Operations

```python
# Common usage in loops
for i in range(5):              # 0, 1, 2, 3, 4
    print(i)

for i in range(1, 6):           # 1, 2, 3, 4, 5
    print(i)

for i in range(0, 10, 2):       # 0, 2, 4, 6, 8
    print(i)

# Reverse iteration
for i in range(10, 0, -1):      # 10, 9, 8, ..., 1
    print(i)

# Converting to list (when needed)
numbers = list(range(5))        # [0, 1, 2, 3, 4]

# Range comparison and operations
r1 = range(5)
r2 = range(5)
print(r1 == r2)                 # True
print(3 in r1)                  # True
print(len(r1))                  # 5

# Slicing ranges (returns new range)
r = range(10)
print(r[2:8:2])                 # range(2, 8, 2) -> 2, 4, 6

# Memory efficiency
import sys
r = range(1000000)              # Uses minimal memory
lst = list(range(1000000))      # Uses much more memory
print(sys.getsizeof(r))         # Small fixed size
print(sys.getsizeof(lst))       # Large, proportional to length
```

### Advanced Range Usage

```python
# Enumerate with custom start
items = ['a', 'b', 'c', 'd']
for i, item in enumerate(items, start=1):
    print(f"{i}: {item}")       # 1: a, 2: b, 3: c, 4: d

# Zip with range for indexing
items = ['apple', 'banana', 'cherry']
for i, item in zip(range(len(items)), items):
    print(f"Index {i}: {item}")

# Creating sequences with specific patterns
# Every 3rd number starting from 2
sequence = range(2, 20, 3)      # 2, 5, 8, 11, 14, 17

# Countdown
countdown = range(10, -1, -1)   # 10, 9, 8, ..., 0
```

## Sequence Type Comparison

| Feature      | str                     | list                | tuple                   | range             |
| ------------ | ----------------------- | ------------------- | ----------------------- | ----------------- |
| Mutability   | Immutable               | Mutable             | Immutable               | Immutable         |
| Item Types   | Characters (str)        | Any type            | Any type                | Integers only     |
| Memory Usage | Interned strings cached | Dynamic allocation  | Small tuples cached     | Constant (lazy)   |
| Primary Use  | Text processing         | General collections | Fixed collections       | Numeric sequences |
| Hashable     | Yes                     | No                  | Yes (if items hashable) | Yes               |

## Performance Tips

### String Performance

```python
# Avoid string concatenation in loops
# Slow:
result = ""
for item in items:
    result += str(item)

# Fast:
result = "".join(str(item) for item in items)

# Use f-strings for formatting (fastest)
name, age = "Alice", 30
formatted = f"Name: {name}, Age: {age}"
```

### List Performance

```python
# List comprehensions are faster than loops
# Fast:
squares = [x**2 for x in range(1000)]

# Slower:
squares = []
for x in range(1000):
    squares.append(x**2)

# Pre-allocate when size is known
size = 1000
lst = [None] * size  # Pre-allocate
for i in range(size):
    lst[i] = compute_value(i)
```

### Tuple Performance

```python
# Tuples are faster for:
# - Creation (when size is small)
# - Iteration
# - As dictionary keys
# - Function arguments/returns

# Use tuples for immutable collections
coordinates = (x, y, z)  # Better than [x, y, z] if immutable

# Named tuples provide structure without class overhead
from collections import namedtuple
Point = namedtuple('Point', ['x', 'y'])
```

## Best Practices

### String Best Practices

1. Use f-strings for formatting (Python 3.6+)
2. Use `str.join()` for concatenating multiple strings
3. Use raw strings for regex patterns: `r"\d+"`
4. Consider `str.casefold()` for case-insensitive comparisons
5. Use `str.strip()` to clean user input

### List Best Practices

1. Use list comprehensions when appropriate
2. Prefer `extend()` over repeated `append()` calls
3. Use `enumerate()` instead of manual indexing
4. Consider `collections.deque` for frequent front insertions
5. Use slicing for copying: `new_list = old_list[:]`

### Tuple Best Practices

1. Use tuples for heterogeneous, immutable data
2. Use named tuples for structured data
3. Use tuple unpacking for multiple assignments
4. Use tuples as dictionary keys when possible
5. Return tuples from functions for multiple values

### Range Best Practices

1. Use range in for loops instead of creating lists
2. Use `enumerate()` when you need both index and value
3. Consider `range` arguments carefully for off-by-one errors
4. Use negative step for reverse iteration
5. Convert to list only when random access is needed

## Common Pitfalls

### String Pitfalls

```python
# Mutable default arguments
def append_to_string(item, string=""):  # Wrong!
    return string + str(item)

def append_to_string(item, string=None):  # Correct
    if string is None:
        string = ""
    return string + str(item)
```

### List Pitfalls

```python
# Mutable default arguments
def append_to_list(item, lst=[]):  # Wrong! Shared mutable default
    lst.append(item)
    return lst

def append_to_list(item, lst=None):  # Correct
    if lst is None:
        lst = []
    lst.append(item)
    return lst

# Modifying list while iterating
lst = [1, 2, 3, 4, 5]
for i, item in enumerate(lst):
    if item % 2 == 0:
        lst.pop(i)  # Wrong! Changes indices during iteration

# Correct approach
lst = [item for item in lst if item % 2 != 0]
```

### Tuple Pitfalls

```python
# Single element tuple requires comma
single = (42)    # This is an integer, not a tuple!
single = (42,)   # This is a tuple with one element

# Unpacking mismatch
data = (1, 2, 3)
a, b = data      # ValueError: too many values to unpack
```

#### 2.2.3 String Performance

```python
import time

# Inefficient string concatenation
def slow_concat(n):
    result = ""
    for i in range(n):
        result += str(i)
    return result

# Efficient string concatenation
def fast_concat(n):
    return "".join(str(i) for i in range(n))

from io import StringIO
def stringbuilder_concat(n):
    buffer = StringIO()
    for i in range(n):

    return buffer.getvalue()
```

### 2.3 Lists - Implementation & Performance

```python
# Lists are dynamic arrays implemented as resizable arrays
import sys

my_list = []
for i in range(10):

import timeit

# List comprehension (faster)
list_comp = lambda: [x**2 for x in range(1000)]

def regular_loop():
```

```python
numbers = list(range(20))
```

#### 4.2.1 String (str) - Immutable Unicode Sequence

```python
# String internment for small strings
a = "hello"
b = "hello"
print(a is b)  # True (interned)

# Unicode handling
unicode_str = "Hello, 世界! 🌍"
print(len(unicode_str))                    # Character count
print(unicode_str.encode('utf-8'))         # Byte representation
print(len(unicode_str.encode('utf-8')))    # Byte count

# String methods deep dive
text = "  Hello, World!  "
print(text.strip())                        # Remove whitespace
print(text.lstrip())                       # Remove left whitespace
print(text.rstrip())                       # Remove right whitespace

# Advanced string operations
data = "apple,banana,cherry"
fruits = data.split(',')                   # ['apple', 'banana', 'cherry']
rejoined = '|'.join(fruits)                # 'apple|banana|cherry'

# String formatting
name = "Alice"

print("Name: %s, Age: %d" % (name, age))   # % formatting (older)

# String searching and validation
text = "The quick brown fox"

# Character classification
```

#### 4.2.2 List (list) - Dynamic Array Implementation

```python
# List internal structure: dynamic array with over-allocation
import sys

lst = []
for i in range(20):
    lst.append(i)
    print(f"Length: {len(lst)}, Size in memory: {sys.getsizeof(lst)}")

# List comprehensions vs traditional loops
# More memory efficient and faster
squares = [x**2 for x in range(10)]
even_squares = [x**2 for x in range(10) if x % 2 == 0]

# Advanced list operations
data = [3, 1, 4, 1, 5, 9, 2, 6]
```

#### 4.2.3 Tuple (tuple) - Immutable Sequence

```python
# Tuple optimization: small tuples cached
small_tuple = (1, 2)
another_tuple = (1, 2)
print(small_tuple is another_tuple)       # May be True (implementation detail)

# Tuple packing and unpacking
coordinates = 3, 4                        # Tuple packing
x, y = coordinates                        # Tuple unpacking

# Multiple assignment
a, b, c = 1, 2, 3
a, b = b, a                              # Swap values

# Named tuples for structured data
from collections import namedtuple
Point = namedtuple('Point', ['x', 'y'])
p = Point(3, 4)

print(p._asdict())                       # {'x': 3, 'y': 4}
```
